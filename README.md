# HTML-and-CSS-Course

## 📌 Projects Contained

### 1. The Core Portfolio Project
A custom web landing environment built from scratch dedicated to student developer **Manal Oraha**. Built using an edgy, high-contrast colorful neon aesthetic, this portfolio acts as a direct demonstration of core native browser competencies. 

**Key Implementations Included:**
*   **Navigation Architecture:** A fully sticky/fixed header component mapping smooth scrolling coordinates with color-changing mouse-hover feedback.
*   **Advanced Image Modification:** Showcases image transformations using inline container-centering, programmatic CSS hue/saturation filters, and custom edge-rounding metrics (`border-radius`).
*   **Media Multi-Layering:** Integrates a responsive stock hero video tag running a continuous muted loop with dynamic, human-readable layered typography overlays centered on top.
*   **Structured Layout Data:** Features a custom two-column grid scheme with targeted size variables alongside clean, responsive structural tabular metrics mapped with explicit interior spacing cell boundaries (`padding`).
*   **State Transitions:** Implements custom mouse-hover triggers causing structural modifications, horizontal element shifts on `<p>` nodes, and complete image opacity layout adjustments (fade-in overlay screens).

### 2. The Bootstrap Responsive Project
This workspace tracks transition goals moving from custom native CSS stylesheets to modular responsive grid utility configurations provided by the Bootstrap layout suite. It implements component features like mobile-ready utility wrappers, pre-built structural columns, and optimized component classes to achieve rapid site deployment scales.
